# Cloud market slide sources

The two charts use separate dates, as requested. Worldwide: Q3 2026. Europe: estimates from a December 2025 European Parliament study, based on sources from 2024 and 2025. Europe is not a measured EU-27-only series; these are not contemporaneous, directly equivalent observations.

## Worldwide

- [Synergy, 29 October 2026](https://www.srgresearch.com/articles/cloud-market-growth-rate-surges-to-well-over-50-per-year-q3-revenues-reach-168-billion): Q3 2026 AWS 26%, Microsoft 19%, Google 16%; remaining providers 39%, calculated by subtraction. Scope: IaaS, PaaS and hosted private cloud revenue. Microsoft is labelled Microsoft Azure in the slide.
- [The Register, 20 November 2025](https://www.theregister.com/2025/11/20/aws_loses_market_share_azure_google/), reporting Synergy: Q3 2025 AWS 29%, Microsoft 20%, Google 13%; remaining providers 38%, calculated by subtraction. The trend arrows are the year-over-year change in percentage points: AWS −3, Microsoft −1, Google +3, others +1.

## Europe

- [European Software and Cyber Dependencies, European Parliament, December 2025](https://www.europarl.europa.eu/RegData/etudes/STUD/2025/778576/ECTI_STU%282025%29778576_EN.pdf), Figure 8, printed page 46, and Table 16, printed page 181: AWS approximately 30%, Microsoft Azure approximately 25%, Google Cloud approximately 15%. Other providers approximately 30%, calculated by subtraction.
- Figure 8 cites the authors' elaboration of Synergy 2024 data. Table 16 reveals a mixed 2024–2025 basis: the July 2025 Synergy aggregate of 70%, global shares and assumptions about regional presence. It explicitly says exact EU-only AWS figures are not publicly broken out. Azure's rationale also refers to Microsoft 365 adoption. These are author estimates, not separately measured provider shares or a uniform annual 2024 series. The slide therefore labels them as estimates with a 2024–2025 source period.
- [Synergy, 24 July 2025](https://www.srgresearch.com/articles/european-cloud-providers-local-market-share-now-holds-steady-at-15) provides the underlying 70% aggregate but no individual European shares.

## Platforms on AWS

Hosting information checked on 2 November 2026, separately from the historical market comparison.

- [Vercel](https://vercel.com/blog/aws-databases-are-now-live-on-the-vercel-marketplace-and-v0) states that its infrastructure runs on AWS.
- [Supabase regions](https://supabase.com/docs/guides/platform/regions) lists AWS deployment regions. This describes managed Supabase Cloud, not self-hosted installations.
- [Neon regions](https://neon.com/docs/introduction/regions) lists AWS regions for new projects; Azure regions are deprecated and cannot accept new projects.

These companies provide their own software and managed services on the underlying infrastructure. The slide does not claim they merely resell AWS or are owned by Amazon.
