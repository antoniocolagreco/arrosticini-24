# SectionTitle

The heading kit: eyebrow, page title, section title with brush underline, double rule and the handwritten aside.

**You provide:** the text. Pick the level; the styles do the rest.

- **Page title** (`a24-page-title`): one per page. May split in two tones, first sentence `primary`, second `forest`. Never more than two colours.
- **Section title** (`a24-section-title a24-brush`): the brush underline is `primary`, starts at the left edge of the text and covers roughly the first two words. One underline per section, never under a page title.
- **Eyebrow** (`a24-eyebrow`): uppercase, `forest`, 3px tracking, with a `primary` middle dot between the two halves.
- **Double rule** (`a24-rule-double`): two 1px `rule` lines 5px apart. Use it to open and close a band (value props, footer). It is not a generic divider; rows use a single `border` hairline.
- **Handwritten aside** (`a24-hand`): at most one per screen, for a joke, never for information. Live text, never baked into an illustration.
- Titles end with a full stop. Sentence case, no title case, no exclamation marks.
