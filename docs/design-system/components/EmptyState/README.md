# EmptyState

Sheep, a title, one line, one action. For empty lists and for the 404 and 500 pages.

**You provide:** the illustration, the title, the line and the action.

- **Empty cart, no orders, no addresses, no cards:** the calm sheep (`sheep_overdrive_off.webp`) and a primary button to the shop or to the add form.
- **Search without results:** repeat the query in the title; the action is secondary, "Mostra tutti i prodotti".
- **404 and 500:** the overdrive sheep (`sheep_overdrive_on.webp`), full page between header and footer, primary "Torna alla home". The 500 also prints the request id in a code chip the visitor can copy.
- The title can be dry and funny; the line under it says plainly what is going on. Never joke about a failed payment.
- One action. No secondary links, no suggestions grid.
- The sheep is decorative (`alt=""`); the title carries the meaning.
