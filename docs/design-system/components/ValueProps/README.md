# ValueProps

The band of three promises under the hero, closed above and below by the double rule.

**You provide:** three items, each an illustration (`town.webp`, `box.webp`, `globe.webp`), a title and one line.

- Always three. Titles in `forest` at `value-title`, text at `body`.
- Side by side from 1000px with `rule-soft` vertical separators; stacked below, with horizontal ones.
- Illustrations are 60px tall and decorative (`alt=""`).
- English titles run longer ("Refrigerated delivery", "Destination: the world"): let the text wrap to two lines, do not shrink the type.
- Home only. Do not reuse the band as a generic feature list.
