# Reference

The mocks the system was drawn from. They show the look; where they disagree with the system, the system wins.

- `home-mock.png`: the home. Follow it for the hero, the value props, the wordmark and the row cards. The product names and prices in it are old.
- `product-list-mock.png`: an earlier product list. Follow it for the stacked card and the page title. Its filter sidebar, sort menu, "I più amati" badge and social icons are not part of the system: the product list has a SearchField only.
